# 検証方針

ISO 19157 の品質要素を物差しにして評価します。対象とする品質要素は次の5つです。

- 網羅性（漏れ＝欠落と、余分＝存在しない・重複した地物）
- 位置正確度
- 主題正確度（属性）
- 論理一貫性
- 時間品質

Overture はさまざまな出典を統合したデータなので、地域やテーマによって品質が大きく異なると考えられます。そのため「日本全体で何%」という1つの数字ではなく、**どこの、何が、どの程度か**を地図と表で示すことを目指します。

## 2段構え

### 統計との比較（広く浅く）

市区町村やメッシュの単位で、全国について公的統計と比較します。量の過不足と、その地域差がつかめます。

ただし、統計との比較には次の限界があります。

- **漏れと余分が相殺される。** 件数比が 1.0 でも正しいとは限りません。
- **位置や属性の誤りは見えない。**
- **定義の違いが混ざる。** 例：「事業所」と「POI」、「課税家屋」と「建物ポリゴン」は同じものを数えていません。

### 地物単位の照合（狭く深く）

パイロット地域で、公的な空間データと地物を1件ずつ照合します。漏れと余分を分けて測り、その結果を手がかりに全国の統計比較を解釈します。

パイロット地域の候補（都市化の程度で層別する）：

- 大都市の中心部（東京23区の一部など）
- 地方都市
- 農山村
- 離島

集計では、人口集中地区（DID）の内か外かでも層別します。

## テーマ別の比較対象

| テーマ | 公的統計（全国比較） | 公的な空間データ（パイロット照合） | 主な指標 |
|---|---|---|---|
| divisions | 国勢調査、全国都道府県市区町村別面積調 | 国土数値情報 行政区域（N03） | 区画数、名称・コードの一致、面積差、境界の IoU、人口差 |
| buildings | 固定資産の価格等の概要調書（家屋棟数）、住宅・土地統計調査 | 基盤地図情報 建築物の外周線、PLATEAU | 棟数比、IoU マッチングによる漏れ率・余分の率、高さの誤差 |
| places | 経済センサス‐活動調査（地域メッシュ統計）、学校基本調査、医療施設調査 | 国土数値情報（学校・医療機関・駅・郵便局・公共施設など）、チェーン店の公表店舗数 | 産業別の件数比、距離と名称類似度による一致率、目視サンプルで正しかった割合 |
| transportation | 道路統計年報、道路施設現況調査、鉄道要覧 | 電子国土基本図の道路中心線 | 種別ごとの延長比、バッファ方式による網羅性（completeness）・正確性（correctness）、接続性 |
| addresses | — | アドレス・ベース・レジストリ、位置参照情報 | 日本のデータの有無、住所構造の適合性 |
| base | — | 国土数値情報（湖沼・河川・海岸線）、JAXA 土地利用土地被覆図 | 面積比、分類の一致率 |

## 時間品質

- `sources[].update_time` の分布を見る
- GERS ID はリリースをまたいで同じ地物を指すので、リリース間の差分で増減と変化の頻度を追う

## 判断基準

差を並べるだけでは結論が出ないので、用途ごとに合格ラインを決めます。用途はまだ決めていません（TBD）。

例：人口集中地区で建物の棟数比 0.9 以上、かつパイロット地域での漏れ率 10% 以下なら、建物分布の分析に使える。

## 着手順

1. 棚卸し（日本分の切り出し、出典の構成、テーマ別件数）
2. divisions（比較的簡単で、集計単位の準備にもなる）
3. buildings（参照データが最も充実している）
4. places（不確実性が大きいが、価値も高い）
5. transportation
6. addresses

## 注意

- 参照データにも誤差があり、定義も違います。一致率を真の値とみなさず、定義の違いを結果に添えて示します。
- 結果を公開するときは、参照データと Overture の双方のライセンスを確認します。
